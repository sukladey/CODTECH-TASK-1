# Big Data Analysis using PySpark

## Internship Project

This project was developed as part of the CODTECH Data Analysis
Internship.

## Project Objective

The objective of this project is to perform Big Data analysis on a large
dataset using PySpark and derive useful business insights.

## Technologies Used

-   Python
-   PySpark
-   Pandas
-   Matplotlib
-   Jupyter Notebook

## Dataset

The dataset simulates an e‑commerce sales system with 100,000 records
including:

-   Order_ID
-   Product
-   Category
-   Price
-   Quantity
-   City

## Project Workflow

1.  Data Generation / Collection
2.  Data Loading using PySpark
3.  Data Cleaning and Transformation
4.  Data Analysis
5.  Visualization
6.  Insights Generation

## Key Analysis Performed

### Sales by Category

Identifies which category generates the highest revenue.

### Top Selling Products

Determines the products with the highest number of units sold.

### City-wise Sales

Analyzes which cities generate the most revenue.

## Insights

-   Electronics category generates the highest sales.
-   Laptops and Phones are the top-selling products.
-   Major sales are generated from metropolitan cities.
